## 5. Hotfix — PostgreSQL RLS Infinite Recursion (`Digest: 3730131510`)
- **Work Completed During Session**:
  - Diagnosed Next.js production SSR error digest (`Digest: 3730131510`).
  - Identified root cause in live Supabase PostgreSQL database: circular dependency / infinite recursion between `trips_select_policy` (referencing `public.trip_assignments`) and `assignments_select_policy` (referencing `public.trips`).
  - Created and deployed `public.get_my_assigned_trip_ids()` as a `SECURITY DEFINER` function with `search_path = public` to evaluate assigned trips without triggering re-entrant RLS evaluation.
  - Updated `trips_select_policy` to use `id in (select public.get_my_assigned_trip_ids())`.
  - Decoupled `assignments_select_policy` and `assignments_admin_crud` to check `public.employees` company boundaries instead of subquerying `public.trips`.
  - Successfully executed migration against linked live Supabase project (`sfdkdebfeispylbfpwmy`) via `supabase db query --linked`.
  - Verified live queries on `trips` and `trip_assignments` returning `{ data: [], error: null }` with zero recursion errors.
  - Verified Next.js routes responding with HTTP 200.
